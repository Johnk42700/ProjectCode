# Emmergent Communication: Is Listener Co-adaptation the Hidden Common Cause?

Code for my bachelor thesis on emergent communication.

## Structure

- `agents.py` — agent definitions
- `game.py` — Lewis reconstruction game: object space, train/test split and losses
- `train.py` — trains one speaker-listener pair in the Lewis reconstruction game
- `tain_pair.py` — main and train pair example
